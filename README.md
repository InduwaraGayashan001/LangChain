# LangChain Article Series - Code Repository

Welcome! This repository contains the **code examples** used in my Medium article series on **LangChain**, a framework for building applications with **Large Language Models (LLMs)**.

The series is beginner-friendly and walks step by step from LLM basics to more advanced topics like memory, RAG, and agents.

---

## 📝 Article Series

1. **[Your First Steps with LLMs and Inference APIs Using LangChain](https://medium.com/@induwaragayashan/getting-started-with-langchain-first-steps-with-llms-and-inference-apis-f9d7a10e7c03)**  
   A practical guide to calling LLMs and understanding modern inference workflows.

2. **[Prompt Templates and Chains in LangChain](https://medium.com/@induwaragayashan/prompt-templates-and-chains-in-langchain-writing-smarter-llm-workflows-59fb41d524dd)**  
   How to turn simple LLM calls into maintainable workflows using prompts and chains.

3. **[Adding Memory to LLMs with LangChain](https://medium.com/@induwaragayashan/memory-in-langchain-teaching-llms-to-remember-conversations-b29c770c79c2)**  
   Building context-aware applications using memory modules.

4. **[Retrieval-Augmented Generation (RAG) with LangChain](https://medium.com/@induwaragayashan/when-llms-need-to-look-it-up-rag-with-langchain-c40b11407e99)**  
   A practical guide to connecting LLMs with external knowledge sources.

5. **[Building Agents and Tools with LangChain](https://medium.com/@induwaragayashan/when-llms-take-action-building-agents-and-tools-with-langchain-443ce8e0475a)**  
   Transforming LLMs from text generators into decision-making systems.
